# Security Policy

This extension reads an Enpass vault and copies secrets to the clipboard —
if you find a security issue, please report it **privately** via GitHub:
Security tab → "Report a vulnerability". Please do not open a public issue
for security reports.

The trust model (in-memory-only snapshots, vault mirroring, Keychain storage,
concealed clipboard copies) is documented in the README's Security model
section — alleged violations of it are exactly what to report.
